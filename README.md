    <h1>README - Conversor de Tallas</h1>

    <h2>Descripción</h2>
    <p>
        Este proyecto es una página web que permite convertir tallas de ropa y calzado entre diferentes sistemas internacionales, incluyendo EU, US y UK, tanto para hombres como para mujeres.  
        La herramienta está diseñada para ser rápida, sencilla y útil para usuarios que compran ropa en tiendas internacionales.
    </p>

    <h2>Características</h2>
    <ul>
        <li>Conversión de tallas de <strong>ropa</strong> (tops y pantalones) para hombres y mujeres.</li>
        <li>Conversión de tallas de <strong>calzado</strong> para hombres y mujeres.</li>
        <li>Interfaz simple y fácil de usar.</li>
        <li>Diseño responsive para móvil y escritorio.</li>
    </ul>

    <h2>Cómo usar</h2>
    <ol>
        <li>Selecciona el tipo de prenda o calzado que deseas convertir.</li>
        <li>Selecciona el género (hombre o mujer).</li>
        <li>Introduce la talla en el sistema de origen (EU, US o UK).</li>
        <li>Presiona el botón de "Convertir" y obtendrás la talla equivalente en otros sistemas.</li>
    </ol>

    <h2>Instalación</h2>
    <p>
        Puedes abrir directamente el archivo <code>index.html</code> en cualquier navegador moderno.  
        No se requiere instalación adicional ni servidores.
    </p>
